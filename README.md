# 🦁 草原动物大迁徙 · Savanna Animal Migration

> 一个**单 HTML 文件**、**纯前端零依赖**的竖屏移动端休闲益智小游戏。
> 横向拖动草原动物方块,靠**重力下落**对齐(类俄罗斯方块),**站满整行即触发「动物大迁徙」消除**;动物从草原下方不断涌现、把整体上顶,**顶满则本场结束**。

含动物能量与潜能技能、连消连击加成、动物图鉴与结算评分。全部卡通 emoji / CSS 手作美术,无外部图片与 CDN,双击 `index.html` 即玩。

---

## ✨ 特性

- 🧩 **零依赖单文件**:一个 `index.html`,无后端、无数据库、无构建,复制到浏览器即运行
- 🎮 **拖拽 + 重力 + 消行**:横向滑动动物条,腾出空位后上方动物自动掉落,凑满整行即消除
- ⚡ **能量与潜能技能**:消耗动物能量激活 6 种动物潜能,激活越多越贵(最高需攒满两管)
- 📯 **动物号角 ×3**:直接补足当前激活所需能量
- 🐃 **野牛来袭**:特定回合从下方涌现愤怒野牛
- 📖 **动物图鉴**:查看各动物的迁徙积分 / 能量 / 潜能
- 💾 **本地存档**:`localStorage` 自动保存,刷新/重开页面进度不丢
- 📱 **竖屏适配**:`100dvh` 适配手机,内容过高可上下滚动;弹窗居中盖屏

## 🎯 玩法规则

1. **棋盘**:9 列 × 11 行的草原网格,放置横向动物条(占 1~4 格)。
2. **拖动调整站位**:横向拖动动物条;只看**最终落点**——拖出去又拖回原位不算数。
3. **重力下落**:每次有效拖动后,所有动物条按重力尽量下落填补空位(像俄罗斯方块)。
4. **完成迁徙(消除)**:某一行被**站满 9 格**即触发「动物大迁徙」,该行动物迁徙隐匿,按种类获得**迁徙积分 + 动物能量**。
5. **连续迁徙(连击)**:同一回合内连消多行有积分加成(2 连迁 +20%,3 连迁 +40% …)。
6. **回合与涌现**:每完成一次拖动 = 1 回合,回合结束**草原下方涌现一行新动物并把整体上顶**;**草原被清空时额外涌现 2 行**。
7. **本场结束**:当已有动物处于最上方,又要涌现新行时,本场结束并按积分给出 S/A/B/C 评价。
8. **能量与潜能**:积攒动物能量,点「激活」选择场上一只动物释放其潜能;成本随激活次数递增。能量不足可用 **📯 号角** 补足。

### 操作
- **拖动动物条**:鼠标拖拽 / 手指滑动(仅水平方向)。
- **激活**:点顶部「激活」→ 棋盘高亮 → 点选一只动物 → 确认释放;点暗处取消。
- **📯 号角 / 📖 图鉴 / 🔄 重新开始**(二次确认)。

### 动物与潜能
| 动物 | 潜能效果 |
|---|---|
| 🦁 狮子 | 朝相邻动物多的一侧伸长并吞并它们一起迁徙 |
| 🐘 大象 | 清除所在列上的所有动物 |
| 🐃 野牛 | 横向冲撞,让所在整行迁徙(高分) |
| 🦓 斑马 | 场上所有斑马一起迁徙 |
| 🐵 猴子 | 随机让 3 只动物迁徙 |
| 🦛 河马 | 让所在整行迁徙,并额外回充能量 |

## 🛠️ 技术实现

- 纯 **HTML / CSS / JavaScript**,无框架、无外部资源。
- **DOM + CSS** 渲染棋盘与动物条;`pointer` 事件实现拖拽;CSS `@keyframes` 实现烟雾 / 粒子 / 金光柱 / 横幅 / 浮动数字等特效。
- 游戏状态集中在一个 `state` 对象;`localStorage`(键 `animalWorldSave_v1`)自动存读。
- 自适应布局:按棋盘实际尺寸计算格子大小,`resize` 时重排。

```text
html纯前端游戏2/
├── index.html   # 游戏本体（HTML + CSS + JS 全在一个文件）
└── README.md
```

> **本地存档说明**:`localStorage` 按"浏览器 + 域名"隔离,换设备 / 换浏览器 / 无痕模式不共享,也不跨设备同步;清除浏览器数据会清空存档。

## 🎨 自定义

- 动物种类 / 积分 / 能量 / 潜能集中在 `index.html` 顶部的 `ANIMALS` 配置。
- 数值平衡(激活成本 `actCost`、涌现节奏、野牛来袭回合 `nextBuffalo`、初始行数等)均可直接调整。
- 美术为 emoji + CSS,想换风格改对应 `.a-xxx` 配色或 emoji 即可。
